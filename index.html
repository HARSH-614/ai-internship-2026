Internship Assignment

Basics of AI & Practical Applications


Submitted by: Sajal Baruah

GU Roll No: US-241-222-0031

Days 1-3: AI, ML & DL

  • History: From the 1950 Turing Test to the Generative AI era (2020+).
  • AI Types: Narrow, General, and Super AI.
  • Hierarchy: Deep Learning is a subset of Machine Learning, which is a subset of AI.
  • ML Workflow: 9 steps from Problem Definition to Deployment.

Days 4-6: Prompting & Office

  • C-R-I-S-P Framework: Context, Role, Instruction, Specifics, Parameters.
  • Techniques: Zero-Shot, One-Shot, Few-Shot, Role-Based.
  • Automation: W-E-P (Word for writing, Excel for equations, PowerPoint for presentations).

Days 7-9: Generative Media

  • Images: S-S-L-R prompt formula (Subject, Style, Lighting, Resolution).
  • Video: Diffusion models using Runway ML and Pika Labs.
  • Audio: ElevenLabs using the V-O-I-C-E formula.
  • Presentations: S-L-I-D-E rules using Gamma AI and Beautiful.ai.

Days 10-13: Tech & Dev

  • Research: NotebookLM and Consensus using the R-E-A-D cycle.
  • Data Analysis: ChatGPT ADA using C-L-E-A-R workflow.
  • Coding (C-O-D-E): Context, Objective, Details, Examples via Copilot.
  • Web Dev (H-C-W): HTML generation, Custom web apps, Website builders.

Days 14-16: Edu, Biz & Ethics

  • Education: Lesson plans & quizzes using P-L-A-N framework.
  • Business: Marketing and finance using the S-C-A-L-E framework.
  • Ethics: Mitigating AI hallucinations, deepfakes, and copyright issues.
  • Golden Rule: Ground, Verify, Cite.

Days 17-20: Project Lifecycle

  • Planning: Setting SMART milestones & Requirement Gathering.
  • Development: Teamwork, Tool Integration, Mentor Guidance.
  • Completion: Final checklist, Report writing, PPT creation.
  • Assessment: Live demonstration, Viva confidence, Feedback loop.

Final Conclusion

AI + Human Intelligence = Smarter Decisions.
